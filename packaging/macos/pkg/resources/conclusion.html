Two permissions, once

AetherDesk needs two permissions before a client can see and use this Mac. In System Settings → Privacy & Security, turn AetherDesk on under:

  1. Screen & System Audio Recording
  2. Accessibility

If AetherDesk isn't in a list, click + and pick it in Applications. The AetherDesk menu-bar item shows whether both are granted and opens these panes too. macOS applies them to a fresh start, so then run in Terminal: aether-agent restart (or log out and in).

Updates keep both permissions.

Pair a client

In Terminal:

sudo aether-agent pair

shows a 6-digit code for 2 minutes. On Linux, run aetherdesk pair and type the code.

Remove

aether-agent uninstall removes the app, the service and agents, the audio device, the logs and the pairings.
