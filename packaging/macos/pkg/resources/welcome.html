AetherDesk host (alpha)

AetherDesk lets you use this Mac from a Linux computer: it streams the screen to the AetherDesk client on Linux and takes its keyboard and mouse.

This installs:

  • AetherDesk.app in Applications, with a menu-bar item that shows its status and checks for updates;
  • a background service that waits for clients, and an agent in each login session, including the login window;
  • the AetherDesk audio device, which plays the Mac's sound on Linux during a session (the Mac's sound pauses for a moment while it loads).

Only clients you pair with a 6-digit code shown on this Mac can connect. Apple Silicon, macOS 14 or later.
